# Working with business context

Use this store with the active dataset in AI Analyst. Inspect its data descriptions and the guide catalog before choosing a business definition.

Select guides by the question, team and period. Read the selected guide's full content and linked source when needed. If meaning is missing or sources disagree, ask for clarification or state the assumption; do not present a guess as company policy.

Keep source references with the analysis. Use the existing read-only data connection, and keep credentials outside this store.
