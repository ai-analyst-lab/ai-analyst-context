# Guides

Add reviewed, task-specific business context here as YAML files. Start from a source the responsible team can confirm.

The course loader expects `id`, `description`, `dataset`, `owner`, `source`, `status`, `reviewed_on`, `review_after` and `content`. Include `scope` to explain the applicable team, question and period. The filename must match the ID, for example `team-topic.yaml` with `id: team-topic`.

Claude can write the syntax using the installed guide loader. You review the meaning. Keep a new guide in draft status until that review; the catalog only offers reviewed guides whose dates and dataset are applicable.

Write a description using the questions people actually ask. Put the complete definition in content. Link the original document in sources/. Do not store expected answer values here.
